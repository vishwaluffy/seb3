## Write a python program to define a function to check the number 1720 is even or odd.
#Aim 
```
To Write a python program to define a function to check the number 1720 is even or odd.
```
#algorithm.
```
1. Start.
2. Define a function that takes a number as an argument.
3. Check if the number is divisible by 2 (even) or not (odd).
4. Return "Even" or "Odd" based on the result.
```
##program
```
def function(num):
    
    if num%2==0:
        print(f"{num} is Even number")
    else:
        print(f"{num} is Odd number")
        
num = int(input())        

function(num)  
```
